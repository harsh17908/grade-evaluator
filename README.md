# Grade Evaluator

Console program in C by Harsh Verma. Enter marks 0–100, get grade with validation.

## Grading
- 90+ → A+
- 80+ → A
- 70+ → B
- 60+ → C
- 50+ → D
- 33+ → E (Pass)
- Below 33 → F (Fail)

## Build
```bash
gcc grade.c -o grade
```

## Run
```bash
./grade
# Windows
grade.exe
```

## Example
```
==== Grade Evaluator ====
Enter marks (0-100): 82
Marks: 82.00
Grade: A
Result: Pass — well done.
```
